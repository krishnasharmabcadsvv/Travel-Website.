# 🇮🇳 Incredible India Travel Guide

A beautifully designed, multi-page travel guide website about India — built purely with **HTML** and **CSS**. No frameworks, no JavaScript, just clean and structured web fundamentals.

---

## 🌐 Live Preview

> Upload to GitHub Pages to get a live link!
> `https:/krishnasharmabcadsvv/Travel-Website.`

## 📁 Project Structure

```
📦 Incredible-India-Travel-Guide/
├── index.html          # Home page with featured destinations
├── destinations.html   # Detailed destination pages
├── travel-tips.html    # Essential travel tips for visitors
├── gallery.html        # Photo gallery of Indian places
├── contact.html        # Contact form and info
└── style.css           # All styles in one unified stylesheet
```

---

## 📄 Pages Overview

| Page | File | Description |
|------|------|-------------|
| 🏠 Home | `index.html` | Hero section + featured destination cards |
| 🗺️ Destinations | `destinations.html` | Jaipur, Goa, Varanasi, Mysore, Kerala, Ladakh |
| 💡 Travel Tips | `travel-tips.html` | Packing, budget, safety, culture, food tips |
| 🖼️ Gallery | `gallery.html` | Grid-based photo gallery of stunning locations |
| 📬 Contact | `contact.html` | Contact form + social media links |

## 🚀 How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://krishnasharmabcadsvv/incredible-india-travel-guide.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd incredible-india-travel-guide
   ```

3. **Open in browser**
   - Simply open `index.html` in any web browser
   - Or use the **Live Server** extension in VS Code for a better experience

---

## 🌍 Deploy on GitHub Pages

1. Push all files to your GitHub repository
2. Go to **Settings → Pages**
3. Under **Source**, select `main` branch and `/ (root)` folder
4. Click **Save** — your site will be live in a few seconds!
